 ## Required Commands:
1.File Operations:
  
   -Mkdir : Creates a directory.
   -cd : moves in directory.
   -touch: Creates empty file.
   -pwd: shows Present working directory.
   -ls: list files.
  
 2. File Management:
  
    -cp: create backup copy files.
    -mv: move & rename Files.
    -rm: Remove file/ Delete files.
    -ls -R: Displays files & Directories recursively.

 3. File Content Operations:
    
     -Vim: It is a Text Editor.
     -i: insert mode.
     -wq: save & quiet.
     -cat: Display file content.
     -head: Display first 10 lines of file.
     -tail: Display last 10 lines of file.
     -wc: Display line, word, character counts.

  4. User Management:
     
     -useradd: Create /add user.
     -passwd: Set password to user.
     -id: Display UID,GID and attach groups.
     -su: Switch to user.
     -whoami: current username.
     -exit: exit from terminal/user.
     
  5. Group Management:

     -groupadd: Creates group.
     -groups: Display groups.
     -gpasswd: set password.

 6. File Permission:

     -touch: Creates empty file.
     -chmod: Change permission.
     -ls -l: Displays file permission.
     -chown: Change owner of File.
     -chgrp: Change group of file.

 7.Permission Challenge:
     -mkdir -p: creates Parent directory.
     -ls -ld: Display the permission of all directories.

  8. Package Management:
     -yum/dnf: package Manager of RedHat Family.
     -apt/dpkg: package Manager of Debian Family.
     -yum update && upgrade: Updates & Upgrades installed Packages.
     -systemctl start: Starts Server.
     -systemctl status: Checks Status.
     -systemctl restart: Restart server.
     -systemctl enable: reboot server.
     
  9. Apache Webserver Configuration:
      - /var/www/html/: Default document root.
      -cd: change directory.
      -curl: Read/fetch Webpage Content.

  10. Process Management:
      
      -ps aux: Displays all running processes.
      -top: Displays processes & system usage in real time.
      -pgrep: Displays PID of Server.

  12. Search & Text Processing:
      
      -grep: Shows specific required content and pattern.
      -grep -i: For casesentive.
      -grep -ic: counts matched received records.
      -sort: sorts records alphabetically.
      -find: Shows specific required content in required Pattern.

  14. Linux Networking:
      
      -hostname: Displays the system hostname.
      -ip addr: shows ip address.
      -ip link: Displays available network interfaces.
      -ip route: Displays the system routing table.
      -ping: test network Connectivity.
      -ss -lntup: Displays listening TCP/UDP ports.
